# Contact Form

A simple HTML contact form project that allows users to provide their contact details and send a message to the support team.

## Features

- Full name input
- Email input
- Subject dropdown
- Message textarea
- Referral source radio buttons
- Product updates subscription checkbox
- Form submission using `POST`

## Getting Started

1. Clone or download this repository.
2. Open `contact.html` in a web browser.
3. Fill in the form and submit it.

## Project Files

- `contact.html` - The contact form page.
- `README.md` - Project documentation.

The form is configured to submit data to `submit_contact.php` using the `POST` method. A PHP backend is required to process submitted form data.
